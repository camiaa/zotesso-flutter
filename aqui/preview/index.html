Quem é Hora Pães?

A Hora Pães nasceu com o propósito de levar sabor, qualidade e aconchego para o seu dia a dia. Trabalhamos com uma grande variedade de pães fresquinhos, bolos caseiros, salgados e cafés especiais.

Objetivo do Projeto

Desenvolver um aplicativo moderno no FlutterFlow conectado ao banco de dados Cloud Firestore, aplicando conceitos de Backend Query, persistência de dados em coleções e experiência de usuário para a Padaria Hora Pães.
